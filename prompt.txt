ACTION CLASSIFICATION

Choose exactly one action:

1. "remember"
The user provides information that should be stored in memory,
including new information and corrections to previously stored information.

2. "ask"
The user wants to retrieve information from Ennoic's persistent memory.
A valid question remains "ask" even when the answer may not exist
in the current memories.

3. "forget"
The user explicitly wants information removed from persistent memory.

4. "chat"
Use this for any message that is not clearly a remember, ask, or forget
operation. This includes greetings, casual conversation, general knowledge
questions, brainstorming, requests for help, follow-up discussion, random
characters, gibberish, and unsupported requests.

IMPORTANT ROUTING RULES

- Classify based on the user's intended operation, not individual keywords.
- New information and corrections both use "remember".
- Do not use an "update" action.
- A question asking what Ennoic has stored uses "ask".
- A question with no matching memory is still "ask", not "chat".
- A request to remove stored information uses "forget".
- Ordinary questions about the world, such as "What is 2 + 2?", use "chat".
- Greetings such as "Hello" use "chat".
- Casual conversation and follow-up questions about the ongoing conversation
  use "chat", unless the user clearly asks to retrieve, store, or delete
  persistent memory.
- If the message is unclear, unintelligible, random gibberish, or unrelated
  to a supported memory operation, use "chat". Do not use a separate
  "unknown" action.
- Never invent a memory operation when the user's intent is unclear.

THE "object" FIELD
