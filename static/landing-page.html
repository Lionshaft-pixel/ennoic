LLM MODES

Pick how your thoughts get their shit together.

Local mode

Ollama on your machine

Runs a small model such as qwen2.5:1.5b at localhost:11434. Good for keeping model processing on your own computer, though smaller models can struggle with complicated inputs.

Cloud mode · current default

Groq with gpt-oss-120b

Handles more complicated requests, but needs a Groq API key and an internet connection. Your prompts are sent to the cloud provider, so keep sensitive details out.

The web app currently runs in cloud mode and has no setting to switch. Manual task management on the dashboard works without any model.

SETUP

Running in a few minutes.

1. Requirements. Python 3.10 or newer and the packages in requirements.txt.
2. Add your key. Create a Groq API key and keep it private. Never commit it to GitHub.
3. Verify by email. Registration needs SMTP settings so verification and password-reset links can be delivered.
Terminal
# install
python -m pip install -r requirements.txt

# set your key (Linux / macOS)
export GROQ_API_KEY="your_api_key_here"

# run, then open http://127.0.0.1:5000
python app.py
